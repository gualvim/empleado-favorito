# Guía del Empleado Favorito

Este es un manual estratégico interactivo diseñado para el crecimiento corporativo y la gestión de carrera.

## Tecnologías Utilizadas

- **React 19**
- **Vite**
- **Tailwind CSS 4**
- **Motion (Framer Motion)**
- **Lucide React (Iconos)**

## Despliegue en Vercel

Para desplegar este proyecto en Vercel, sigue estos pasos:

1. Conecta tu repositorio de GitHub a Vercel.
2. Vercel detectará automáticamente que es un proyecto de Vite.
3. Asegúrate de que los comandos de build sean:
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
4. ¡Disfruta de tu aplicación!

## Desarrollo Local

1. Instala las dependencias:
   ```bash
   npm install
   ```
2. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```
